Most trip planners hand everyone the same list. This one starts from a profile of how *you*
travel — pace, taste, what you want out of a place — and reads the real review signal for
each candidate, so the itinerary it builds is weighted toward things you would actually
enjoy.

Built with Expo and a Node backend, with the AI reasoning in the loop. A personal project,
and an experiment in making a recommendation feel personal rather than popular.
